# NOVORA Internship Blog

A modern and responsive internship portfolio website created to document my On-the-Job Training (OJT) journey as a BS Information Technology student from Bicol University College of Science.

## Overview

This project serves as my personal internship dashboard and blog where I showcase:
- Weekly internship experiences
- Technical support activities
- OJT progress tracking
- Skills and tools used
- Documentation and accomplishments

## Features

- Responsive portfolio-style layout
- Weekly internship blog entries
- OJT progress tracker
- Skills and experience highlights
- Organization information section
- Interactive Read More functionality
- Clean and modern UI design

## Technologies Used

- HTML
- CSS
- JavaScript
